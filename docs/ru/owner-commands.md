# Команды

Каналы, роли и пользователи выбираются из стандартных пикеров Discord; `set`/`unset` и `access grant`/`access revoke` автодополняют опции `path`/`command`.

`/nep` видна каждому участнику с самого начала; доступ проверяется для каждой команды в момент вызова, а не через видимость команд в Discord. Владельцы (`bot.owners`) всегда могут выполнять любую команду. Остальным нужно разрешение: `/nep access grant <command> [role] [user]` открывает один ключ команды (напр. `memory.show`), целую группу (напр. `memory`) или все команды (`*`) всем (без роли/пользователя), роли или пользователю; `/nep access revoke` отменяет разрешение; `/nep access list` показывает текущие разрешения. Без разрешения участник без прав владельца, выполняющий `/nep`, получает эфемерный ответ "Not allowed". `private.show`, `private.forget` и `private.purge` доступны только владельцам и исключены из всех разрешений; `access grant` отклоняет их, а `access list` не показывает. Группа `mentor` доступна только владельцам точно так же и не может быть выдана через разрешения.

| Команда | Описание |
|---|---|
| `/nep status` | Модель, калибровка, квоты (включая счётчик картинок и модель изображений), статус памяти по серверу, приватный чат вкл/выкл и количество приватных файлов |
| `/nep reload` | Перезагрузить конфигурацию и промпты сейчас же |
| `/nep ping [role]` | Отправить минимальный запрос к одной или всем ролям модели (`talk`, `analyzer`, `classifier.text`, `classifier.media`, `classifier.video`, `mentor`; `/nep ping classifier` пингует все три классификатора) и показать модель, задержку, провайдера, токены или ошибку; после `classifier.video` показывает `youtube: API key — {status}` (например `ok`, `not needed (yt-dlp ok)`, `missing (blocked)`); после `classifier.text` — `web: API key — {status}` (`ok`, `missing` или `off`). `role:image` проверяет `image.model` по публичному листингу моделей провайдера (один бесплатный GET, без генерации) и подтверждает, что модель зарегистрирована и выдаёт изображения; успешная проверка не гарантирует, что генерация удастся. Без указания роли проверка image идёт последней. Не учитывается в `llm.maxRequestsPerDay` и работает на паузе или во время прогрева |
| `/nep pause` | Остановить всю активность, сбросить память на диск и выгрузить; текущий прогон ментора останавливается и его отчёт публикуется до сброса. `data/` безопасно редактировать на паузе |
| `/nep resume` | Перезагрузить память из `data/` и продолжить; отказывает, если хоть один JSON-файл не разбирается, и перечисляет сломанные |
| `/nep interject [channel]` | Немедленно вклиниться в разговор в указанном канале |
| `/nep initiate [channel]` | Немедленно начать тему в указанном канале |
| `/nep draw <text> [self]` | Нарисовать одну картинку через промпт рисования. Ответ только вам (эфемерный с прикреплённой картинкой). Тратит баланс в счёт `image.maxPerDay`, но не в лимит участника. Отклоняется на паузе. НЕ зависит от `features.imageGeneration` |
| `/nep set <path> <value>` | Переопределить значение конфигурации (пишет в `config.local.json`) |
| `/nep unset <path>` | Удалить переопределение конфигурации |
| `/nep rule add <text>` | Добавить правило в `prompts.local/rules.md` |
| `/nep rule list` | Показать правила с нумерацией |
| `/nep rule remove <number>` | Удалить правило по номеру |
| `/nep model show` | Показать активные модели для каждой роли (`talk`, `analyzer`, `classifier.text`, `classifier.media`, `classifier.video`, `mentor`) |
| `/nep model set <role> <id>` | Установить модель для роли (`talk`, `analyzer`, `classifier.text`, `classifier.media`, `classifier.video`, `mentor`) |
| `/nep memory show <user> [section] [limit] [order]` | Без секции: краткая сводка. Секции: `character`, `style`, `relationship`, `affinity`, `aliases`, `interests`, `details`, `episodes`, `raw` (сохранённый JSON). Секции-списки принимают `limit` 1..100 (по умолчанию 25) и `order`: `rank` (по умолчанию, с разделителем на границе видимой части) или `recent`. Сохранённые ссылки на участников заменяются на текущее имя (кроме `raw`) |
| `/nep memory channel [channel]` | С указанным каналом: полная сохранённая заметка (назначение, темы, тон, количество сообщений, активность, самые активные авторы). Без канала: таблица всех каналов, которые знает персонаж, по дате последнего сообщения |
| `/nep memory server` | Серверные заметки: как люди общаются, как начинаются разговоры, внутренние шутки, факты о себе, плюс количество профилей, каналов и записей лорбука |
| `/nep memory refresh <user>` | Принудительно обновить портрет участника |
| `/nep memory forget <user>` | Удалить сохранённый профиль и приватную память |
| `/nep memory affinity <user> [score] [reason]` | Показать или установить отношение (-100..100) |
| `/nep memory wipe <confirm>` | Стереть всю память анализатора для этого сервера, включая приватные файлы; для подтверждения введите точное имя сервера |
| `/nep private show <user>` | Показать приватную память участника: отношения, интересы, детали, эпизоды, приватное и эффективное отношение, сегодняшний счётчик ответов. Нет приватного слоя — простой ответ, не ошибка. Только для владельцев; нельзя выдать через разрешения |
| `/nep private forget <user>` | Удалить только приватную память участника; публичный профиль сохраняется. Только для владельцев; нельзя выдать через разрешения |
| `/nep private purge <user>` | Удалить сообщения бота в ЛС с участником (сканирует до `private.purgeMaxMessages`), затем его приватную память. Сообщения участника остаются. Отклоняется на паузе. Только для владельцев; нельзя выдать через разрешения |
| `/nep alias add <user> <name>` | Добавить псевдоним в чате; подтверждается сразу |
| `/nep alias remove <user> <name>` | Удалить псевдоним из чата |
| `/nep learned list` | Список уроков с id, кто научил, количество наблюдений |
| `/nep learned add <text>` | Добавить урок вручную (без учителя, подтверждено) |
| `/nep learned remove <id>` | Удалить урок |
| `/nep lore add <title> <keys> <text> [always]` | Добавить или перезаписать запись лорбука; запись с тем же заголовком заменяется и помечается как владельческая, и анализатор её больше не трогает |
| `/nep lore list [query]` | Список записей лорбука |
| `/nep lore show <id>` | Показать запись лорбука |
| `/nep lore remove <id>` | Удалить запись лорбука |
| `/nep emoji status` | Показать рейтинг эмодзи: размер, топ-10 имён с количеством, время последнего заполнения из истории |
| `/nep emoji rescan` | Очистить рейтинг использования и пересчитать из истории каналов |
| `/nep gifs status` | Показать библиотеку GIF: размер, топ-10 с хэндлом, количеством и подписью или именем, время последнего заполнения из истории, отправлено сегодня / `gifs.maxPerDay` |
| `/nep gifs rescan` | Очистить рейтинг использования и пересчитать GIF из истории каналов |
| `/nep warmup run` | Запустить или возобновить полный прогон: каналы, затем люди, затем сервер |
| `/nep warmup users [member]` | С участником: построить или перестроить его профиль сейчас; без участника: перестроить профили всех подходящих |
| `/nep warmup channels [channel]` | С указанным каналом: описать его заново сейчас; без канала: все доступные каналы |
| `/nep warmup server` | Пересобрать серверные заметки и лорбук |
| `/nep warmup people` | Список подходящих участников |
| `/nep warmup status` | Показать прогресс прогрева и расход токенов |
| `/nep warmup stop` | Немедленно прекратить работу прогрева; текущий запрос отменяется, прогресс сохраняется для возобновления через `run` |
| `/nep warmup reset` | Очистить прогресс прогрева; сохранённая память не трогается |
| `/nep mentor add message:<link or id> text:<comment>` | Добавить кейс: сообщение персонажа, которое вы отклонили, плюс одно предложение о том, что в нём не так. Оба параметра обязательны. Сообщение должно быть от персонажа; ссылка на другой сервер, личное сообщение, канал, недоступный боту, удалённая цель ответа и чужое сообщение отклоняются |
| `/nep mentor anchor id:<case> message:<link or id>` | Добавить ещё один момент к существующему кейсу. Те же отказы, что и у `add`, плюс: неизвестный кейс, удалённый кейс, не-reply кейс, то же сообщение дважды, момент с пустой историей или заканчивающийся сообщением персонажа, и превышение `mentor.anchor.max` |
| `/nep mentor cases` | Список кейсов: id, состояние (`new`, `passing`, `failing`), цель, последний балл, число моментов (если есть), текст до 80 символов |
| `/nep mentor remove <id>` | Убрать кейс |
| `/nep mentor run <id>` | Запустить полный цикл для одного кейса. Отвечает сразу, что запущен. При включённом `features.mentorAutoFix` проваленный прогон продолжается циклом исправления. При наличии канала администратора (`bot.dryRunChannelId`) отчёт публикуется туда; без него ответ указывает на `/nep mentor status` и `/nep mentor show <id>` |
| `/nep mentor check` | Воспроизвести сохранённые ситуации каждого активного кейса, у которого есть прогон, с `mentor.check.samples` сэмплов на каждую. При наличии канала администратора публикуется один общий отчёт; без него ответ указывает на `/nep mentor status` и `/nep mentor show <id>` |
| `/nep mentor stop` | Отменить текущий прогон, включая запрос к модели |
| `/nep mentor show <id>` | Отчёт последнего прогона: ситуации, ответы, баллы, комментарии, диагностика при наличии, секция исправления с каждой попыткой и id изменения для отмены |
| `/nep mentor wrong <id> <reason>` | Сообщить ментору, что он оценил этот кейс неправильно, и почему; сохраняется как контрпример для будущих оценок |
| `/nep mentor status` | Модель, включён или нет, потрачено токенов / лимит, кейсы по состояниям, текущий прогон (показывает `, stopping` пока остановка ожидается), `autofix: on|off`, `changes:` количество с отменёнными и устаревшими переопределениями, и последний завершённый прогон (`last:`): кейс, результат, медиана overall, оценённые ответы, токены и время завершения |
| `/nep mentor log` | По строке на каждое записанное изменение, от новых к старым: id, кейс, слой, цель, время, сводка. Отменённые изменения помечены `(undone)` |
| `/nep mentor undo <id>` | Вернуть то, что одно изменение заменило. Отказывает, если содержимое изменилось с тех пор (`changed since`) или уже отменено |
| `/nep mentor rebase <name>` | Пересобрать одно локальное переопределение промпта из текущего отслеживаемого файла с повторным применением записанных патчей. Используется после деплоя, который изменил отслеживаемый файл промпта. Отказывает с `edited by hand`, если локальный файл изменён вне ментора (сравнивает хеш с `writtenHash`), и с `already current`, если отслеживаемый файл не менялся |
| `/nep access grant <command> [role] [user]` | Открыть команду, группу или `*` всем (по умолчанию), роли или пользователю. `private.*` и `mentor.*` исключены; см. выше |
| `/nep access revoke <command> [role] [user]` | Отозвать разрешение у всех (по умолчанию), роли или пользователя |
| `/nep access list` | Список всех текущих разрешений доступа |
