## `llm`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `baseUrl` | `"https://openrouter.ai/api/v1"` | Эндпоинт chat completions |
| `model` | `"anthropic/claude-opus-4.6"` | ID модели |
| `temperature` | `1` | Температура сэмплирования |
| `maxOutputTokens` | `700` | Макс. токенов на выходе |
| `maxRequestTokens` | `50000` | Жёсткий лимит токенов на запрос |
| `safetyMargin` | `0.9` | Доля `maxRequestTokens` для бюджетирования |
| `timeoutMs` | `300000` | Таймаут запроса (мс) |
| `pingTimeoutMs` | `30000` | Таймаут для запросов `/nep ping` (мс) |
| `retries` | `2` | Повторы при временных ошибках |
| `maxRequestsPerDay` | `300` | Дневной лимит запросов |
| `provider` | `null` | Объект маршрутизации OpenRouter `provider`, передаётся как есть; `null` ничего не отправляет |

`llm.provider` задаёт поле маршрутизации провайдера OpenRouter в каждом запросе, например `{ "ignore": ["some-provider"] }` или `{ "order": ["anthropic"], "allow_fallbacks": true }`. Если аккаунт OpenRouter ограничивает допустимых провайдеров, игнорирование единственного оставшегося провалит каждый запрос с ошибкой "No endpoints found". После изменения настроек провайдера выполните `/nep ping`, чтобы проверить доступность каждой роли модели.

## `relationships`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `damping` | `true` | Демпфировать изменения, уводящие от нуля; изменения к нулю применяются полностью |
| `dampingPower` | `1` | Экспонента коэффициента демпфирования; большие значения затрудняют достижение краёв шкалы |
| `maxDeltaPerUpdate` | `15` | Макс. изменение балла за обновление |
| `historySize` | `10` | Сохраняемых изменений отношения на участника |
| `directTriggerCount` | `6` | Прямых взаимодействий для принудительного раннего обновления |

При включённом `damping` изменение, уводящее балл дальше от нуля, масштабируется как `(1 - |score| / 100) ^ dampingPower`, поэтому крайние значения требуют устойчивых усилий; изменение обратно к нулю применяется в полную силу. Балл хранится с дробной точностью и показывается как целое число; `/nep memory affinity` устанавливает его напрямую без демпфирования.
